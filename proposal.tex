\noindent\textbf{Project Title}

Automated Knowledge Artifact Creation: Using Multiple AI Tools to Explore Privacy and Data Protection in AI Systems

\vspace{8pt}

\noindent\textbf{Project Abstract}

This project uses multiple free AI tools to create a knowledge artifact on ``Privacy and Data Protection in AI Systems,'' a topic Neeli Prasad emphasized throughout the seminar. The core idea is to explore how different tools approach the same content, documenting my process and comparing the results. I'll start by collecting and researching privacy in AI using Perplexity, then use Claude API to analyze the seminar transcript, synthesize the key concepts, and generate comprehensive content. After that, I'll use QuillBot to create alternative versions of the content with different writing styles to see how this affects clarity and audience engagement. SlidesAI.io will automatically create a presentation from the curated material. Throughout this process, I'll track prompts, execution times, and quality differences, ultimately comparing which tool combinations work best for this topic. The final deliverable will be a comprehensive package: curated research, multiple content versions, a generated presentation, full methodology documentation, comparative analysis with metrics, and my conclusions about what I learned from orchestrating these tools.

\vspace{8pt}

\noindent\textbf{Target Seminar}

Human-AI Collaboration by Neeli Prasad. Prasad spent considerable time discussing privacy concerns, data governance, consent mechanisms, and the need for ethical safeguards in AI deployment. Privacy protection stood out as particularly important, it's not just a technical issue but one that affects people directly. That's why I chose to focus on it for this project: it's concrete, practically relevant, and demonstrates a real challenge in human-AI collaboration.

\vspace{8pt}

\noindent\textbf{AI Tools to Be Used}

\begin{itemize}
  \item Perplexity: research and information gathering
  \item Claude API: analysis, content synthesis, and text generation
  \item QuillBot: writing refinement and alternative versions
  \item SlidesAI.io: automated presentation generation
\end{itemize}
